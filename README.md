# Мой кошелёк · версия 3

Личное независимое PWA для учёта доходов и расходов. Визуальная структура главной страницы адаптирована по присланному скриншоту Spendee: денежный поток за месяц, столбцы за шесть месяцев, история по дням, поиск сверху, пять нижних вкладок и крупная кнопка «+». **Это не официальный Spendee, не копия его исходного кода и не банковское приложение.**

## Что умеет

- Главная: выбранный месяц, доходы, расходы, разница, интерактивный график за полгода, последние операции по датам, расходы за сегодня.
- Переключение месяца стрелками или нажатием на столбец графика. Кнопка «Этот месяц» возвращает к текущему.
- Нижние вкладки: **Главная · Счета · Обзор · Бюджеты · Больше**.
- Поиск операций сверху; фильтры истории по типу, категории, датам и сумме.
- Нажатие на операцию открывает редактирование; кнопка **+** предлагает доход, расход, скриншот или перевод.
- Доходы, расходы, переводы в той же валюте, категории, кошельки и лимиты.
- OCR скриншотов одной банковской операции на бесплатной библиотеке Tesseract.js (русский + английский). Распознанные данные **всегда подтверждаются пользователем** перед записью. Поддерживаются JPG, PNG, WEBP; после первого обращения OCR скачивается из стороннего CDN и требует интернета. Точность не гарантируется.
- Импорт CSV из Spendee, экспорт CSV, локальная резервная копия/восстановление JSON.
- Интерфейс PWA кэшируется для офлайн-открытия. Операции хранятся в IndexedDB на устройстве.

## Как получить свою историю из отдельного файла

Вместе с этим ZIP может распространяться отдельный файл **`moy-koshelek-lichnaya-istoriya-Spendee.json`**. Он содержит операции из присланного CSV, категории (включая сохранённые из HTML имена и цвета) и один счёт «Кошелёк Наличные». Значения положительных сумм считаются **доходами**, отрицательных — **расходами**, как согласовано с пользователем. Валюта — RUB.

1. Откройте работающий сайт «Мой кошелёк».
2. Вкладка **Больше → Резервная копия → Восстановить из JSON**.
3. Выберите указанный отдельный JSON-файл с телефона.
4. Подтвердите полную замену текущей базы. После восстановления на главной появится история операций по месяцам.

**Внимание:** восстановление **удаляет текущие операции** из локальной базы и заменяет их содержимым файла. Если в новой PWA уже ведутся расходы, сначала сохраните копию текущей базы JSON. **ЛИЧНЫЙ JSON НЕЛЬЗЯ ПУБЛИКОВАТЬ**: он не включён в папку сайта и должен остаться приватным. В CSV нет заметок, подробных счетов и переводов; восстановить их из него невозможно.

Вкладка **Счета** показывает математический баланс по внесённым операциям. **Это не банковский остаток**, поскольку в Spendee много лет учитывались преимущественно доходы. Для корректного остатка в дальнейшем требуется учёт всех расходов и/или калибровка начального остатка.

## Запуск и установка на телефон

Содержимое **папки `moy-koshelek-pwa`** из ZIP нужно выложить на собственный HTTPS-сайт (например, бесплатный статический хостинг). Личный файл JSON на сервер не загружать.

- Компьютер для локального теста: запустите `python -m http.server 8000` из папки `moy-koshelek-pwa`, откройте `http://localhost:8000`.
- Телефон: откройте HTTPS-адрес сайта в Safari или Chrome и выберите «На экран Домой» / «Установить приложение».
- Простое открытие `index.html` через «Файлы» не запускает PWA в штатном режиме: для service worker нужен HTTPS или `localhost`.

## Ограничения и сохранность

- **Нет синхронизации между устройствами.** На другом телефоне база пустая, пока не восстановите JSON. Регулярно делайте резервные копии и храните их вне браузера в защищённом месте.
- **OCR — вспомогательная функция**, ошибки в суммах, датах или магазинах возможны; проверяйте перед сохранением. Скриншот после распознавания не сохраняется в историю или JSON.
- Нет прямого подключения к банку, фонового доступа к его операциям, автоматического определения дубликатов между разными источниками со 100% точностью, денежных переводов между разными валютами или конвертации.
- Файлы и база не зашифрованы, поэтому важно защищать устройство и резервные копии.
- Бесплатный OCR работает в браузере; при первом запуске нужен интернет для CDN и языковых моделей, дальнейшая доступность может зависеть от браузерного кэша.
- Исходный код JavaScript и стили доступны для редактирования без сборки и подписок.

## Проверка

Проверены синтаксис JS, шаблоны страниц на данных из CSV, помесячные расчёты и комплектность архива. В этой среде Chromium блокирует навигацию системной политикой, поэтому **визуальное тестирование в браузере и iOS-тестирование пока не выполнены**.
